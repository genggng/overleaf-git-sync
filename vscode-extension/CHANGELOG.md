# Changelog

## 0.2.1

- Show the latest successful sync as a local date and time, with the full Git
  commit retained in the tooltip for diagnostics.

## 0.2.0

- Add a native Overleaf Activity Bar container and live Sync Status tree.
- Show project health, branch, working-tree state, committed changes to push,
  conflicts, interrupted pushes, last sync state, and remote freshness state.
- Add view-title and inline project buttons for pull, preview, push, verify, and
  recovery, with file-event and configurable periodic local refresh.

## 0.1.0

- Initial MVP with project discovery, Workspace Trust protection, status bar,
  secure stdin authentication, command progress, Output logging, push preview
  and confirmation, pull, verify, and interrupted-push recovery.
